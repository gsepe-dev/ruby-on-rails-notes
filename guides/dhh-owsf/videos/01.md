## Stale Reads
- Use `create_or_find_by` to avoid stale reads.
- Unlike `find_or_create_by`, which first queries the database and initializes a new object if no matching record is found, `create_or_find_by` attempts to create the record first. If a matching record already exists, the database's unique constraint handles the conflict, allowing the existing record to be retrieved instead. Otherwise, the new record is created.
